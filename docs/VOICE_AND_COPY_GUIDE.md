# The Narrow Path Voice and Copy Guide

The Narrow Path should sound clear, human, Catholic, and restrained. It should
not sound like marketing copy, a motivational poster, or an assistant explaining
every decision it made.

## Default Voice

- Say what the page is and what the user can do there.
- Prefer concrete nouns and verbs over slogans.
- Use the fewest words that preserve the meaning.
- Assume the reader can understand ordinary Catholic language.
- Explain a rule once, where it affects a decision.
- Use headings as labels, not taglines.
- Keep factual content, instructions, and reflection distinct.

## Remove or Rewrite

- Catchy headings that do not help navigation.
- Repeated summaries of content already visible on the page.
- Defensive disclaimers and explanations of what a page is not.
- Meta language about the app, article, profile, review process, or editorial
  intent.
- Stock contrasts such as "not just X, but Y" and "the goal is X, not Y."
- Generic encouragement that could appear on any page.
- Multiple sentences where a label, number, or short instruction is enough.

## Page Copy Pattern

1. A literal page title.
2. One short description only when the title is not sufficient.
3. Clear section labels.
4. Instructions beside the action they govern.
5. Optional reflection or devotional material in its own labeled section.

## Editing Test

Before publishing, ask:

1. Does this sentence add information or help the user act?
2. Is the same point already stated nearby?
3. Does this sound like something a person would naturally say?
4. Can it be shortened without losing meaning?
5. Is editorial or implementation reasoning leaking into public copy?

If a sentence fails those tests, delete it or rewrite it.
